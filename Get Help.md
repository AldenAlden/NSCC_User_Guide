### ASPIRE 2B Support

For ASPIRE 2B, users should use the **ASPIRE 2B Service Desk** as the primary support channel for:

- System access or login issues
- Project or account-related requests
- Job submission or scheduler issues
- Software and application support
- Storage and filesystem issues
- Service degradation or system incidents
- Other ASPIRE 2B enquiries

### Information to Provide When Reporting an Issue

When reporting an issue, provide sufficient information to assist troubleshooting, such as:

- **User ID**
- **Project ID**, where applicable
- **Job ID**, where applicable
- **Approximate date and time** of the issue
- **Error message or observed behaviour**
- **Relevant screenshots or logs**, where available
